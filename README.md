# Simple Inventory Management System

## Project Description
A REST API developed using Node.js and Express.js to manage inventory products. Product information is stored in a JSON file.

## Technologies Used
- Node.js
- Express.js
- JavaScript
- JSON
- Postman

## Installation
1. Clone the repository.
2. Run npm install.
3. Start the server using node server.js.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /getProducts | Display all products |
| POST | /addProduct | Add a product |
| DELETE | /deleteProduct/:productId | Delete a product |
| PUT | /updateProduct/:productId | Update a product |

## Data Storage
Products are stored in data/products.json.
